# Release dependency notices

`LibreSSL-COPYING` is the unchanged `COPYING` file from LibreSSL 4.1.0,
retrieved from Dyne's source mirror:
https://files.dyne.org/musl/sources/libressl-4.1.0.tar.gz.
It accompanies the LibreSSL headers and static archives supplied by the Dyne
musl toolchain and included in avena's musl release package. The release
script checks the bundled LibreSSL version before using this notice.
